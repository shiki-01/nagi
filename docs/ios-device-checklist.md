## 4. 診断ログ（D-1）

`diag/keyboard.log` に直近 200 行だけ残す。ホストアプリの「入力テスト」タブで表示・消去できる。入力内容を含むため、
デバッグ用であり、リリースビルドでは無効にする（配布前チェック項目）。
