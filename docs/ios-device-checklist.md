- 設定タブ（`docs/ios-settings.md`）:
  - 上部の「シンプル / 詳細」で項目が増減する。再起動後も選択が残る。切り替えても値は変わらない
  - コアの項目（ライブ変換・LLM・プロファイル・学習・予測など）を変更 → キーボードを開き直さずに（次の focusIn で）反映される。診断ログに `reload_config ok=true` が出る。範囲外の値は項目の下にエラーが出て元に戻る。「キーボードを開き直すと反映」と出る項目（`update.auto_check` など）は開き直しで反映される
  - 設定を 1 つでも変えたあと、キーボードを起動し直しても値が消えない（自動生成の `config.toml` を上書きしない。`conversion.sync_budget_ms` が 30 のままか、変更した値が残るか）

  - iOS 固有: トグル入力（オン→同じキー連続タップで あ→い、オフ→タップは「あ」のみ）、フリック感度・判定距離（小さくすると短い移動でフリック）、フリックの案内表示オフ、⌫の連打（開始までの時間・間隔）、キーボードの高さ（低め/標準/高め・倍率）、キーの間隔・角丸、片手モード（左/右に寄る。候補バーは全幅のまま）
  - かな/英字のレイアウト割り当て（`qwerty-kana` を選ぶとローマ字入力になる）が、キーボードを開き直すと反映される
  - 触覚（弱/中/強）: **フルアクセスなし（現状 `RequestsOpenAccess: false`）で振動するか**。しない場合は、触覚にはフルアクセスが要ると判断して案内を出す
  - キー入力の音: 端末の「キーボードのクリック」をオンにして、設定で「システムのクリック音」を選ぶと鳴るか（既定はオフ）
  - 診断ログのオン/オフが、入力テストタブのスイッチと連動する
  - 長押しの判定時間（`flick.long_press_ms`）: 短くする/長くすると、レイアウトの `longPress` ポップアップが出るまでの時間が変わる
- ホストアプリのタブ構成・案内（`App/OnboardingView.swift` `DataStatusView.swift` `AboutView.swift`）:
  - 初回起動で「はじめに」シートが 1 度だけ自動表示される。閉じる／下スワイプ後は再起動しても出ない。ホームの「セットアップの案内を表示」で再表示できる
  - 「設定アプリを開く」で設定アプリが開く（このアプリのページ。キーボードの追加は 設定 > 一般 > キーボード から行う）

  - 手順 3 の「データ画面を開く」、手順 4 の「入力テストを開く」で該当タブへ移動してシートが閉じる
  - データタブ: 辞書・モデルの有無、サイズ、場所、モデルの種類（xsmall / small）、使用中のモデルの印が実際の配置と合う。「ホームの取り込み機能を開く」でホームへ移る。メモリ（使用中・あと使える量・上限の推定）と「LLM が使える見込み」の表示（ホストアプリの値であり、拡張の実測ではない点が文言どおりか）
  - About タブ: バージョン表示が TestFlight のバージョン・ビルド番号と一致する。辞書・モデルの出典画面。nagi.shiki-01.com のリンクが開く。「開発者向け」から Probes・結果が従来どおり使える（Probe の実行、結果のコピー・共有・エクスポート・クリア）
  - タブが増えたことで「その他」に畳まれていないか（タブ数 6 以上は iPhone で「その他」になる）
- レイアウト段階 2・管理画面（`docs/ios-keyboard-layout.md`）:
  - toggle: 同梱の `toggle-alpha`（ガラケー式英字。設定のレイアウト割り当てで英字に選ぶ）で「abc」を連続タップ → a→b→c→a と置き換わる。1 秒あけると新しい文字が追加される。別のキーを押すと確定して次の文字から始まる。英字シフトとの組み合わせ（大文字のまま置き換わる）
  - toggle（かなモード）: かなのレイアウトに toggle キー（JSON を取り込んで確認）を置き、入力中に連続タップで下線の文字が置き換わる（コアの backspace + 挿入）。変換候補・確定への影響がないか
  - longPress: `toggle-alpha` の各キーを長押し（既定 350ms）→ 数字のポップアップが出て、離すと入力される。指を横に滑らせて選べる。左右端のキーでもポップアップが画面外に切れない。キーの下へ大きく外して離すと取り消し。短く押すだけなら通常のタップ。設定の長押し時間の変更が効く
  - shortcut: 取り込んだ JSON の shortcut キー（`steps` に text と moveLeft を並べて「（）」を入れてカーソルを間に置く等）。入力中の文字は先に確定される。未知の action を含めると、そこで止まる
  - 片手モード: 設定で左/右にするとキーボード上の空き側に「⇄」「↔」が出る。⇄で左右が入れ替わり、↔で全幅に戻る。ホストアプリの設定画面にも反映される。幅 0.9 でもボタンが押せる大きさか
  - レイアウトタブ: 同梱とユーザーの一覧、JSON の貼り付け取り込み（不正な JSON で日本語のエラー）、ファイル取り込み、共有（ShareLink）、削除（割り当て中なら既定に戻る）、かな/英字への割り当てがキーボードを開き直すと反映される、プレビューの表示
  - URL スキーム: Safari で `nagi://layout?data=<base64url>` を開く → アプリが起動して取り込み結果のアラートが出る（不正な data ではエラー文）

## 4. 診断ログ（D-1）

`diag/keyboard.log` に直近 200 行だけ残す。ホストアプリの「入力テスト」タブで表示・消去できる。入力内容を含むため、
