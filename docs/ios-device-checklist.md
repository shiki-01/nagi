  - `initialize` に capabilities（`input_method: touch`、環境、メモリ上限）を送る。診断ログの `set_environment … budgetMB=` が 150 以上の妥当な値（拡張は約 177）で、プロファイルが従来と変わらない（上限が小さい端末では軽いプロファイルに制限される）
  - 12 キーの文字表: 起動時の診断ログに `get_key_table ok=true`。フリックのポップアップの表示が従来と同じ（あ行〜わ行・句読点の 5 文字）。`ok=false` のときは複製表で表示される
  - JSON-RPC のエラー応答（コアは生きている）は無応答の失敗に数えない。コア無応答の 3 連続で作り直し、2 回を超えると直接入力になる。直接入力のあと、キーボードを開き直す（focusIn）とコアの再生成を試みて、変換が復帰するか
- 部分確定とカーソル（M4）: 「きょうはいいてんきですね」と入力 → 変換前の入力中に ←（変換前のカーソル移動）で下線の途中へキャレットを動かす → 候補バーで「今日は」を選ぶ。本文の手前の文字が削られず、「今日は」+ 残りの入力中が正しく並ぶ。キャレットが先頭・中ほど・末尾の 3 通りで確認。診断ログの `host partialCommit … caretToEnd=` を確認
- 入力欄の切替（M5/P3）: 入力中（下線あり）に別の入力欄へタップで移る（同じアプリ内の別フィールド）。前の欄の文字は残り、新しい欄に文字が混ざらない・候補バーが空になる。診断ログに `document changed`。パスワード欄 → 通常欄 → パスワード欄と切り替え、そのたびに `set_context secure=…` が出る（パスワード欄で学習・文脈が止まる）。トグル入力の途中で別の場所をタップしてカーソルを動かし、同じキーを押しても直前の文字が置き換わらない
- パスワード欄の診断ログ: かな 12 キーを押しても `send <secure>` となり、押したキーが分かる内容がログに残らない
- ジェスチャの取り消し（M2）: ⌫を押したまま画面端からのスワイプ・通知センター・コントロールセンターの引き出し、または別の指でホームインジケータ操作をして指が奪われたとき、連打が止まる（消し続けない）。連打は 1 回の押下で最大 150 文字。長押しキーのポップアップ、フリックキーのハイライト（押下中の行が前面に出たまま残らない）も取り消しで元に戻る
- レイアウトの検証強化（L6/M3）: 5 行以上や行の高さ比の合計が 4.5 を超える JSON は取り込めない（日本語のエラー）。id の形式違反・name なし・label が 16 文字超・未知の `kana` 名・存在しない `layout.target`・steps の action/text の両指定などが取り込み時に弾かれる。同梱の 8 種はすべて読める
- かなレイアウトで shift キー（カスタム JSON）を押しても何も起きない（英字モードの大文字化にだけ効く）
- レイアウト段階 2・管理画面（`docs/ios-keyboard-layout.md`）:
  - toggle: 同梱の `toggle-alpha`（ガラケー式英字。設定のレイアウト割り当てで英字に選ぶ）で「abc」を連続タップ → a→b→c→a と置き換わる。1 秒あけると新しい文字が追加される。別のキーを押すと確定して次の文字から始まる。英字シフトとの組み合わせ（大文字のまま置き換わる）
  - toggle（かなモード）: かなのレイアウトに toggle キー（JSON を取り込んで確認）を置き、入力中に連続タップで下線の文字が置き換わる（コアの backspace + 挿入）。変換候補・確定への影響がないか
  - longPress: `toggle-alpha` の各キーを長押し（既定 350ms）→ 数字のポップアップが出て、離すと入力される。指を横に滑らせて選べる。左右端のキーでもポップアップが画面外に切れない。キーの下へ大きく外して離すと取り消し。短く押すだけなら通常のタップ。設定の長押し時間の変更が効く
  - shortcut: 取り込んだ JSON の shortcut キー（`steps` に text と moveLeft を並べて「（）」を入れてカーソルを間に置く等）。入力中の文字は先に確定される。未知の action を含めると、そこで止まる
  - 片手モード: 設定で左/右にするとキーボード上の空き側に「⇄」「↔」が出る。⇄で左右が入れ替わり、↔で全幅に戻る。ホストアプリの設定画面にも反映される。幅 0.9 でもボタンが押せる大きさか
  - レイアウトタブ: 同梱とユーザーの一覧、JSON の貼り付け取り込み（不正な JSON で日本語のエラー）、ファイル取り込み、共有（ShareLink）、削除（割り当て中なら既定に戻る）、かな/英字への割り当てがキーボードを開き直すと反映される、プレビューの表示
  - URL スキーム: Safari で `nagi://layout?data=<base64url>` を開く → アプリが起動して取り込み結果のアラートが出る（不正な data ではエラー文）
