# iOS 追加要望・アイデア

実装順の整理は `docs/mobile-roadmap.md`、確認事項は `docs/ios-device-checklist.md`。

## 1. 要望（ユーザー指定）

1. **設定項目の洗い出しと実装**: できるだけ細かく設定できるようにする。「シンプルモード」と「詳細モード」を用意し、詳細モードで細部まで調整できる
2. **キーボードの既定レイアウト**: QWERTY（かな / 英字）、フリック（かな / 記号）、記号、数字、絵文字などを用意する
3. **紹介サイト** `nagi.shiki-01.com`: Svelte 5 + Master CSS（rc）。アプリ紹介
4. **キーボードのレイアウト編集（サイト上の GUI）** `nagi.shiki-01.com/custom-keyboard`（名称は任せる）:
   - azooKey のように、キー配置とキーの動作を自由に設定できる。ただしスマホの小さい画面での設定は煩雑なので、サイトの GUI で簡単に細かく設定できるようにする
   - キーごとに、種類（文字入力 / フリック / トグル / ショートカット 等）、入力できる文字、サイズを設定できる
   - 仕様は `docs/ios-keyboard-layout.md`

## 2. 設定項目の候補

詳細は `docs/ios-settings.md`（実装時に更新）。

## 3. 機能のアイデア（便利そう・面白そうなもの）

### 入力・変換
- 予測変換（直前の確定文脈から次の語を提案。候補バーに常時表示）
- 学習の強さ・忘却速度の調整、学習のオン/オフ、シークレット（パスワード欄・指定アプリで学習停止）
- ユーザー辞書（単語登録。ホストアプリ + 選択テキストから登録）、スニペット（短い読みで定型文）
- 顔文字・絵文字の読みからの候補（「にこ」→😊）、絵文字の履歴・よく使う順、肌色の選択
- 日付・時刻・曜日・和暦の入力（「きょう」「いま」「れいわ」）、電卓（「1+2=」→3）、単位変換
- 半角/全角・カタカナ・ローマ字の相互変換、数字の漢数字・全角化、郵便番号→住所（辞書が許せば）
- 英単語の予測と自動スペース、スペル補正、日英混在の自動判定
- 句読点の自動置換（、。⇄，．）、括弧の自動閉じ、連続入力の「ー」「っ」の補助
- 再変換（確定済みテキストの選択 → 読みに戻して変換）
- スタイル変換（丁寧語・口語・要約・誤字修正など。LLM。デスクトップの Phase 4 と共通）
- 変換候補の長押しで学習の削除（この候補を忘れる）

### 操作
- ⌫の長押し連打 + スワイプで単語単位の削除、スペースバーのスワイプでカーソル移動
- 左右フリックでカーソル移動、スペース長押しでカーソル移動モード（トラックパッド化）
- キーの長押しで記号（QWERTY の数字行など）、片手モード（左右寄せ）、キーボード高さの調整
- フリックの感度・判定距離・ポップアップの表示、キーのサイズ・余白、タップの触覚・音
- ダークモード / テーマ（色・角丸・背景画像）、アクセントカラー
- 入力モード別の自動切替（URL 欄は英字、数字欄は数字配列）
- キーボードの中にクリップボード履歴・定型文のタブ、「貼り付け」ワンタップ
- ホストアプリのカスタム キーマップ共有（書き出し/読み込み、サイトのギャラリー）

### その他
- 設定のバックアップ/復元（JSON 書き出し、iCloud はプライバシー方針に反しないか要確認）
- 学習データの全削除、使用統計（端末内のみ・送信なし）の表示（打鍵数・変換精度の推移）
- アクセシビリティ（VoiceOver ラベル、ダイナミックタイプ、ハイコントラスト、触覚のみの通知）
- 初回案内（キーボード追加 → フルアクセスの説明 → 辞書・モデルの取得）
- 辞書・モデルの更新確認と取得（Wi-Fi のみ・容量表示）
- ウィジェット/ショートカットアプリ連携（辞書登録、クリップボードから登録）
